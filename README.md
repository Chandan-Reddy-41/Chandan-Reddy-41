## Featured Projects

### 🧠 AI News Event Clustering & Timeline Reconstruction
*End-to-end unstructured NLP pipeline and interactive dashboard for tracking news event evolution.*
> **Tech Stack:** Python, Sentence-Transformers, Hugging Face, Agglomerative Clustering, Plotly, Streamlit

- **Architected** an end-to-end NLP workflow grouping related news articles into semantically meaningful event clusters using dense vector embeddings and agglomerative clustering algorithms.
- **Engineered** a modular architecture separating offline embedding generation and vector caching from application layers, reducing dashboard latency and optimizing compute resources.
- **Deployed** an interactive Streamlit application featuring Plotly timeline reconstructions and dynamic automated event summaries for exploratory analytics.

### 📊 Retail Customer Intelligence & Large-Scale Analytics
*Statistical modeling and customer segmentation processing over 1.07M+ transactional records.*
> **Tech Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, RFM Segmentation, Pareto Analysis

- **Processed and analyzed** a dataset of **1.07M+ transaction records**, Performing data wrangling, anomaly detection, and feature extraction.
- **Implemented** RFM (Recency, Frequency, Monetary) segmentation and Pareto distribution modeling, identifying that **85.2% of revenue originated from the UK** and **91.6% was generated by core Champion & Loyal customer segments**.
- **Delivered** strategic data-driven insights for inventory planning, customer lifecycle retention, and cross-market purchase behavior.
